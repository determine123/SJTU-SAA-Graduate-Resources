## 计算方法

建议按“问题定义 → 算法假设 → 误差来源 → 数值实验 → 结果解释”整理每一节笔记。程序输出一个数字还不够，需写清输入、停止条件、误差度量和失败情形。

整理数值线性代数实验时，同时保存系数矩阵、右端项、算法、残差与参数。残差小不自动说明解的误差小，还应考虑问题的条件性。对于迭代方法，明确区分相邻迭代差与方程残差。

本地复习文件包含特定日期的考试说明和预测，应与通用知识笔记分开；后续学期不能直接沿用其考试范围或允许携带物品的说法。

补充资源：[MIT 18.335J 资源目录](https://ocw.mit.edu/courses/18-335j-introduction-to-numerical-methods-spring-2019/pages/resource-index/)。这门外校课程可补充数值方法知识，学习顺序以自己的课程大纲为准。

## 矩阵理论

每个定理旁记录对象所属的数域、维度与必要条件；不要把实对称、复 Hermitian、正规矩阵的一组性质直接套到任意方阵。计算实例应同时给出符号推导与数值检验，并解释两者的精度差异。

分解实验应明确使用转置还是共轭转置，记录重构残差；求特征值时注意重复特征值与特征向量空间维数不是同一概念。整理证明时保留关键推理，而不是只收录截图答案。

补充资源：[MIT 18.06](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/) 用于线性代数基础复习，不能替代研究生课程的完整内容。

## 计算机辅助设计

曲线实现应写清控制点、节点向量、次数、参数区间与边界约定。尤其区分“次数 degree”和“阶数 order”：常用约定下，阶数等于次数加一。

B 样条程序需要检查节点非降序、节点与控制点数量关系、重复节点处的分母处理及参数右端点行为。检查基函数非负性和单位分解时需限定适用参数区间；端点插值性质也必须结合节点是否夹持判断。

模型文件应记录软件版本、单位、坐标系以及外部链接依赖。公开样例优先使用自行构造的控制点和模型，避免把课程原题或第三方 CAD 模型当成自有内容发布。

补充资源：[SciPy BSpline 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.BSpline.html)。可用成熟实现作数值对照，但需让次数、节点、控制点和外推设置一致。

## 叶轮机械非定常流动

算例笔记建议分为几何、网格、物性、边界条件、物理模型、时间离散和后处理七部分。先确认量纲与参考量，再比较不同算例的系数和频率。

非定常结果至少记录时间步长、每步收敛标准、舍弃的初始过渡段和采样区间。周期波动、平均量与瞬时量应分开描述；单次计算或单张流场图不能代替网格与时间步长敏感性分析。

补充资源：[SU2 教程](https://su2code.github.io/tutorials/home/)。教程中的翼型、涡轮级等案例可用于熟悉流程，本仓库暂未复现，不能据此声称得到验证结果。
