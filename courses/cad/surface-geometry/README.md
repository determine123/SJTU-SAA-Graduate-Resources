# 参数曲面的基本形式核对

由个人 CAD 学习笔记与符号验证脚本整理，使用 AI 辅助。未收录教师题面截图、身份信息或提交文件；这是一份计算推导笔记，不代表课程官方答案。

考虑参数曲面：

$$r(u,v)=(u-u^3/3+uv^2,\ v-v^3/3+vu^2,\ u^2-v^2).$$

令 $h=1+u^2+v^2$。求一阶偏导并计算内积，可得第一基本形式系数为：

$$E=G=h^2,\quad F=0.$$

采用有向法向量 $n=(r_u\times r_v)/h^2$，其长度为 1。第二基本形式系数为：

$$L=n\cdot r_{uu}=2,\quad M=n\cdot r_{uv}=0,\quad N=n\cdot r_{vv}=-2.$$

主曲率满足 $\det(II-kI)=0$。这里 I 表示第一基本形式的矩阵，不是单位矩阵。代入后得到 $k^2h^4-4=0$，因此主曲率为 $2/h^2$ 和 $-2/h^2$。

由此高斯曲率为 $-4/h^4$、平均曲率为 0。反转法向量会同时改变第二基本形式与主曲率的符号，但不改变高斯曲率。

## 核对的意义

原个人解答记录了与课件打印系数不一致的情况。这里保留可复算的推导：按上述参数曲面与法向约定，得到 `(L,M,N)=(2,0,-2)`。这只是对本例与约定的计算结果，不推断其他版本题目或课件的情况。
