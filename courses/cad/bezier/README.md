# 三次平面 Bézier 曲线细分与连续性





给定 R0=(0,0)，R1=(2,2)，R2=(3,2)，R3=(3,0)。在 t0=1/2、t1=2/3 处分割。以下各段均采用独立局部参数 s∈[0,1]。

（a）三段曲线的控制点

原曲线 R(t)=(6t-3t², 6t-6t²)，R′(t)=(6-6t, 6-12t)。

对任意子区间 [u,v]，其三次 Bézier 控制点可写为：

P0=R(u)，P1=R(u)+(v-u)R′(u)/3；

P2=R(v)-(v-u)R′(v)/3，P3=R(v)。

故从起点到终点依次有：

左段 [0,1/2]：

L0=(0,0)，L1=(1,1)，L2=(7/4,3/2)，L3=(9/4,3/2)。

中段 [1/2,2/3]：

M0=(9/4,3/2)，M1=(29/12,3/2)，

M2=(23/9,13/9)，M3=(8/3,4/3)。

右段 [2/3,1]：

N0=(8/3,4/3)，N1=(26/9,10/9)，N2=(3,2/3)，N3=(3,0)。

用 de Casteljau 算法也得到同样结果：先在原曲线 t=1/2 处分割，再在右段局部参数 s=(2/3-1/2)/(1-1/2)=1/3 处分割。第二次不能直接使用 s=2/3。

（b）位置连续条件

记修改后的中段控制点为 Q0,Q1,Q2,Q3，外侧两段保持不变。

位置连续（G0/C0）的充要条件是：

Q0=L3=(9/4,3/2)，Q3=N0=(8/3,4/3)。

仅要求位置连续时，Q1 和 Q2 可任意改变。

# 单位切向连续与凸包分类

（c）单位切向量连续条件

三次 Bézier 曲线起、终点导数分别为 3(Q1-Q0)、3(Q3-Q2)。

左段末端方向 L3-L2=(1/2,0)，单位方向为 (1,0)。

右段起点方向 N1-N0=(2/9,-2/9)，单位方向为 (1,-1)/√2。

因此两端单位切向量连续（G1）的充要条件为：

Q1=(9/4+a,3/2)，Q2=(8/3-b,4/3+b)，其中 a>0、b>0。

正号保证同向，严格大于零保证端点导数非零。仅要求共线而允许反向，不能保证单位切向量连续。

这并不要求导数长度相等。若额外要求三个独立局部参数下 C1 连续，则 a=1/2、b=2/9；本节讨论单位切向连续，不强加这些额外约束。

（d）凸包顶点及特殊情况

记 A=Q0=(9/4,3/2)，B=Q3=(8/3,4/3)，

C=Q1=(9/4+a,3/2)，D=Q2=(8/3-b,4/3+b)。

两条控制点所在直线交于 H=(5/2,3/2)。当 a=1/4 时 C=H；当 b=1/6 时 D=H。凸包边界顶点按周向排列如下（首尾相连）：

① 0<a<1/4，0<b<1/6：四边形 A → C → D → B。

② 0<a≤1/4，0<b≤1/6，且至少一个取等号：三角形 A → H → B。其余控制点落在边上；a=1/4、b=1/6 时 C=D=H。

③ a>1/4，0<b≤1/6：三角形 A → C → B，D 在内部或边上。

④ 0<a≤1/4，b>1/6：三角形 A → D → B，C 在内部或边上。

⑤ a>1/4，b>1/6：四边形 A → B → C → D。

上述五类穷尽 a>0、b>0 的全部情况。a=0 或 b=0 会造成端点导数为零，不满足（c）的单位切向量定义，因此不列入。

# 分类依据与计算核验

凸包分类的推导

采用以 H 为原点的可逆仿射坐标变换：

(x,y)=H+ξ(1/4,0)+η(1/6,-1/6)。

于是 A=(-1,0)，B=(0,-1)，C=(p,0)，D=(0,q)，

其中 p=4a-1>-1，q=6b-1>-1。

仿射变换保持凸性、共线性和凸包顶点关系，因此只需讨论两坐标轴上这四点的凸包。

当 p<0、q<0，四点分别位于两条负半轴上，各点均为极点；p=q=0 或其中一个为0时，重合点或共线中间点不再单独构成顶点。

当 p>0、q≤0，D 位于三角形 ABC 内部或边上，所以只保留 A、C、B；交换两坐标轴得到 p≤0、q>0 的情况。

当 p>0、q>0，四点分布于两轴的四条半轴上，周向顺序为 A、B、C、D。将 p、q 的符号换回 a、b，即得到前页五类结果。

术语说明

本节求四个控制点的凸包，即包围曲线的控制凸包。

严格数学意义下，曲线像集自身的最小凸包一般包含弧形边界，不能直接等同于控制点多边形。这里的多边形分类仅指控制点凸包。

复算方法
