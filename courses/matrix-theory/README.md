## 结构与特征空间

本地解答中的矩阵是：

```text
A = [ 3 -2 -4 ]
    [-2  6 -2 ]
    [-4 -2  3 ]
```

令 $v=(2,1,2)^T$，可以验证 $A=7I-vv^T$ 且 $v^Tv=9$。

因此 $Av=-2v$；若 $v^Tx=0$，则 $Ax=7x$。三维实向量空间分成 v 张成的一维子空间和它的二维正交补。

特征多项式为 $(\lambda+2)(\lambda-7)^2$。特征值 -2 的代数重数为 1，特征值 7 的代数重数为 2。对应特征空间为：

- $E_{-2}=\operatorname{span}\{(2,1,2)^T\}$。
- $E_7=\{x:2x_1+x_2+2x_3=0\}=\operatorname{span}\{(1,-2,0)^T,(0,-2,1)^T\}$。

第二组向量虽然线性无关，但内积为 4，并不正交。求出特征空间的一组基，不等于已经完成正交化。

## 正交归一化

取三个单位向量：

$$q_1=(2,1,2)^T/3,$$
$$q_2=(1,0,-1)^T/\sqrt2,$$
$$q_3=(-1,4,-1)^T/(3\sqrt2).$$

令 $Q=[q_1,q_2,q_3]$、$D=\operatorname{diag}(-2,7,7)$，则

$$Q^TQ=I,\qquad AQ=QD,\qquad A=QDQ^T.$$

重特征空间内可选取不同正交基，软件输出也可能改变列顺序和符号。核对时应检查向量所属的特征空间与分解关系，而不是只逐元素比较向量。

## 投影形式与矩阵幂

设 $P=vv^T/9$、$R=I-P$。直接计算可得 $P^2=P$、$R^2=R$、$PR=0$ 和 $P+R=I$。于是

$$A=-2P+7R.$$

由幂等性，对非负整数 k 有

$$A^k=(-2)^kP+7^kR.$$

两个特征值均非零，本例还有

$$A^{-1}=-P/2+R/7.$$

这是把原学习解答中的特征空间结果进一步整理为投影形式，便于理解重复特征值的作用。

## 原笔记勘误

原 PDF 把首行是 `(2,1,2)`、其余行为零的阶梯形称作 `RREF(A-7I)`。该矩阵与原矩阵行等价，但主元未归一化，不能称为最简行阶梯形。正确形式为：

```text
rref(A-7I) = [1  1/2  1]
            [0   0   0]
            [0   0   0]
```

这与约束 $2x_1+x_2+2x_3=0$ 等价，因此不改变原特征空间的结论。公开版更正了这个中间步骤。
