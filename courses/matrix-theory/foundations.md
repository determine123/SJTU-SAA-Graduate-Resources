## 1. 子空间：先检查零元与封闭性

经过原点只是必要条件，不是充分条件。例如集合 $C=\{(x,y):y=x^2\}$ 包含 $(1,1)$ 与 $(-1,1)$，但不包含二者的和 $(0,2)$，所以不是子空间。

对固定向量 $v_1,v_2$，集合 $W=\{av_1+bv_2:a,b\in\mathbb R\}$ 是子空间：零向量对应系数 0；两个线性组合的和、任意标量乘积仍为这两个向量的线性组合。结论不要求 $v_1,v_2$ 线性无关。

可逆 n 阶矩阵的集合不是矩阵空间的子空间，因为不含零矩阵；也可用 $I+(-I)=0$ 说明加法不封闭。此处 n 为正整数。

### 张成空间的最小性

设 $S$ 为向量集合，$\mathcal F$ 为包含 S 的所有子空间。它非空，因为整个环境向量空间属于其中。

每个 $V\in\mathcal F$ 都必须包含 S 中向量的一切有限线性组合，因此 $\operatorname{span}(S)\subseteq\bigcap_{V\in\mathcal F}V$。另一方面，$\operatorname{span}(S)$ 本身就是包含 S 的子空间，所以该交集包含于它。两边相等。

## 2. 共轭转置与 Frobenius 范数

对任意复数矩阵 $A\in\mathbb C^{m\times n}$：

$$\operatorname{tr}(A^*A)=\sum_{j=1}^n\sum_{i=1}^m|a_{ij}|^2.$$

右边各项非负，因此迹为零当且仅当 A 为零矩阵。这也是 Frobenius 范数平方的表达式。复数情形必须使用共轭转置，不能直接换成普通转置；例如 $A=[i]$ 时 $A^TA=[-1]$。

## 3. 线性变换与坐标矩阵

反射 $M(x,y,z)=(x,y,-z)$ 的标准矩阵是 $\operatorname{diag}(1,1,-1)$，所以保持线性组合。

对于投影 $P(x,y,z)=(x,y,0)$，若输入基与输出基不同，坐标矩阵的第 j 列必须是 $P(u_j)$ 在输出基下的坐标，而非标准坐标。

本地例子使用：

```text
输入基 U: (1,0,0), (1,1,0), (1,1,1)
输出基 V: (-1,0,0), (0,1,0), (0,1,-1)
```

令 U、V 也表示以上向量按列排列的矩阵，标准投影矩阵为 D。则坐标矩阵 $C=V^{-1}DU$ 为：

```text
C = [-1 -1 -1]
    [ 0  1  1]
    [ 0  0  0]
```

可以用 $VC=DU$ 交叉验证方向，没有必要在数值程序中显式求逆。

## 4. 零空间与秩—零化度

对矩阵

```text
B = [1 2 3]
    [4 5 6]
```

齐次方程给出 $x+2y+3z=0$、$4x+5y+6z=0$。消去 x 得到 $y=-2z$，进而 $x=z$。因此

$$\operatorname{Null}(B)=\{t(1,-2,1)^T:t\in\mathbb R\}.$$

这是过原点的一条直线。生成集只有一个向量，而零空间是它的所有实数倍；两者不要混淆。B 的秩为 2、零化度为 1，相加等于列数 3。

## 5. 一范数与二范数的比较

对 $x\in\mathbb R^n$，

$$\|x\|_2\le\|x\|_1\le\sqrt n\|x\|_2.$$

左侧由 $(\sum|x_i|)^2\ge\sum|x_i|^2$ 得到，右侧由 Cauchy–Schwarz 不等式得到。

下界常数 1 在只有一个非零分量的向量上取等号；上界常数 $\sqrt n$ 在各分量绝对值相等且非零的向量上取等号，因此这两个常数不能分别增大和减小。若改写为 $\|x\|_1/\sqrt n\le\|x\|_2\le\|x\|_1$，需同步改变比较方向与常数。

## 6. Gram–Schmidt：保留中间向量

按以下输入重新计算：

```text
u1 = (1,0,0,-1)
u2 = (1,2,0,-1)
u3 = (2,1,-1,1)
```

令 $w_1=u_1$，并逐次减去在已有正交方向上的投影，可得：

```text
w1 = (1,0,0,-1)
w2 = (0,2,0,0)
w3 = (3/2,0,-1,3/2)
```

归一化结果为：

$$q_1=(1,0,0,-1)^T/\sqrt2,$$
$$q_2=(0,1,0,0)^T,$$
$$q_3=(3,0,-2,3)^T/\sqrt{22}.$$

核对不止是单位长度，还需两两正交及张成空间相同。这里

$$u_1=\sqrt2q_1,\quad u_2=\sqrt2q_1+2q_2,$$
$$u_3=q_1/\sqrt2+q_2+(\sqrt{22}/2)q_3.$$

系数矩阵上三角且对角非零，因此两个向量组张成同一个三维子空间。一般输入若线性相关，某个中间向量可能为零，不能直接除以其长度。

## 7. Cramer 法则的秩一更新证明

设 A 可逆，列向量为 $a_i$，且 $Ax=b$。令 $A_i$ 是用 b 替换 A 的第 i 列得到的矩阵，则

$$A_i=A+(b-a_i)e_i^T=A(I+A^{-1}(b-a_i)e_i^T).$$

对列向量 c、d，有 $\det(I+cd^T)=1+d^Tc$。由行列式关于列的多重线性展开可证明该恒等式：选两个或更多更新列的项包含平行列，行列式为零；仅保留不选和只选一列的项。

代入 c、d，使用 $A^{-1}b=x$ 与 $A^{-1}a_i=e_i$，可得

$$\det(A_i)=\det(A)(1+e_i^Tx-e_i^Te_i)=\det(A)x_i.$$

因为 $\det(A)\ne0$，所以 $x_i=\det(A_i)/\det(A)$。证明用到可逆性；不能对奇异矩阵直接除以其行列式。此式适合理论推导，不表示大型数值线性系统应逐列计算行列式求解。

## 8. 参数线性系统的极限

本地手写例子对应系统：

```text
x1 + t*x2 + t^2*x3 = t^4
t^2*x1 + x2 + t*x3 = t^3
t*x1 + t^2*x2 + x3 = 0
```

系数矩阵行列式为 $(t^3-1)^2$。替换第二列的行列式为 $t^3-t^6$，因此实数 t 不等于 1 时：

$$x_2(t)=\frac{-t^3}{t^3-1},\qquad \lim_{t\to+\infty}x_2(t)=-1.$$

复算时应逐项展开替换列的行列式，避免误配幂次。本例的极限为 -1，与原手写解答一致。
